# py-exodus (Ultima III: Exodus in Python) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a clean, complete, turn-based reimplementation of *Ultima III: Exodus* in Python 3.10+ using `pygame-ce`, reusing the existing binary maps, XML tables, EGA sprite assets, and audio from `gdx-exodus`.

**Architecture:** A lightweight state machine (`StartScreen`, `OverworldScreen`, `TownScreen`, `CombatScreen`, `DungeonScreen`, `RosterScreen`, `ShrineScreen`, `BookScreen`, `FinalScreen`) driving a 2D tile viewport, a 3D wireframe vector corridor renderer for dungeons, and a keyboard/text prompt stream in the scrolling HUD log for commands and NPC dialogues.

**Tech Stack:** Python 3.10+, `pygame-ce` >= 2.5.0, standard library (`struct`, `xml.etree.ElementTree`, `json`, `pathlib`).

**Spec:** [2026-11-07-py-exodus-design.md](file:///sto/src/gdx-exodus/docs/superpowers/specs/2026-11-07-py-exodus-design.md)

## Global Constraints

- Platform: Linux (Python 3.10+).
- Core external dependency: `pygame-ce` only.
- Window scale: Base resolution 320×200 integer scaled 3× to 960×600 using nearest-neighbor blitting.
- Asset path resolution must be case-insensitive / normalized to prevent Linux filesystem bugs.
- All vendor shopping, NPC dialogues, and player queries must run through the HUD text prompt stream (no floating popup windows).
- Background music uses streaming `.ogg` tracks transcoded from `.mid` to ensure zero-dependency Linux audio playback.

## Review Focus

1. **Conflict Map Loading on Case-Sensitive Filesystems**: `CNFLCT_*.ULT` files loaded regardless of uppercase or lowercase naming.
2. **OutOfBounds Grid Boundaries**: Moving off edges in Sosaria wraps around; in combat and dungeons, moving off-grid is blocked or triggers retreat.
3. **Party Death & Wipeout**: When all 4 party members reach 0 HP or drown in whirlpool, game transitions cleanly to death/resurrection at Castle British rather than crashing.
4. **Line of Sight & Ranged Attack Clipping**: Ranged weapon missiles (arrows, magic bolts, cannons) stop at walls/mountains and hit the first blocking creature.
5. **Turn-based Input Locking**: Commands like Attack or Cast wait for target direction without dropping keypresses or corrupting active turn order.
